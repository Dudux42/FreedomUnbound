# Freedom Unbound: what's new

## v0.1.2-alpha (test release)

## Game
- Accented and non-English text now shows correctly in game.

## Launcher
- What's new: this page, shown once after each update and from the home screen.
- Report a bug: zips your recent logs, system info, settings (personal paths and names removed) and mod list. Saves, save keys and save details are never included.
- Discord button in the bug report window and on this page, for news, help and bug reports.
- Update notice when a newer release is out. Nothing downloads until you choose Update.
- Game log: each session is logged to the logs folder in your data folder. The newest 10 are kept.
- Screenshots: a button on the home screen opens the folder F12 saves to.
- Keyboard and gamepad navigation now reach Play from the sidebar.

## Saves
- Automatic save backups (the newest 5 are kept) with Restore, plus manual backups.
- Import a save from the launcher.
- "Back up, then play" skips the backup when your save hasn't changed.
- Export now keeps keyboard and gamepad focus correctly.

## Controls
- Gamepad buttons and keyboard keys can be remapped in Settings > Controls.
- Separate left and right stick dead zones, and a "Swap camera axes" option.
- "Screenshot saved" message after F12.

## Known issues
- The Fill display option is still greyed out. It will come in a later version.
