# Ground rules

- Game files never enter git. That includes the disc image, decrypted or encrypted executables, generated code, overlays, analysis dumps, and saves.
- Disc identity and executable hashes must be measured from the disc, never guessed. The measured USA release values are recorded in DISC.md and the game profile.
- Windows on this machine comes first.
- This repository holds our code only.
- Every mod we create must set `"author": "DuduX42"` in its `mod.json` manifest, unless the owner explicitly requests otherwise.
