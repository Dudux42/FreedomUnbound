# Freedom Unbound — Alpha 0.1.4

Windows x64 distribution of the Freedom Unbound launcher and native runtime.
This repository provides fresh-install release downloads and public documentation.
Development source, internal tooling and private keys are not part of this layout.

## Download and install

1. Open [Alpha 0.1.4](https://github.com/Dudux42/FreedomUnbound/releases/tag/v0.1.4-alpha).
2. Download `FreedomUnbound-0.1.4-alpha-windows-x64.zip` and its checksum text file.
3. Extract the complete ZIP into a new folder. Keep its DLLs, overlays and scripts together.
4. Run **FreedomUnbound.exe** and select your own supported USA PSP game image
   of Monster Hunter Freedom Unite (`ULUS10391`) during setup.

Requirements: Windows x64, a Vulkan-capable GPU/driver, an AVX-capable CPU and
the Microsoft Visual C++ x64 runtime. Your saves and preferences are stored
separately from the program. No game image, original executable, personal save,
installed mod pack or locally derived preview cache is bundled.

## What's new

- Verified mod downloads, with progress, cancellation and installed-version labels.
- **Freedom Unbound Official Mod Page** is included; add other public GitHub
  indexes and expand/collapse each group to organize its mods.
- **F9** opens the in-game mod manager; **F10** toggles an installed Freedom Unbound HD pack.
- Pre-game LAN Host/Join controls, alongside the equipped-hunter preview cards
  and per-hunter loading from earlier builds.

Mods are separate downloads through the launcher or
[Freedom Unbound Mods](https://github.com/Dudux42/FreedomUnboundmods).
See [release notes](RELEASE_NOTES.md) for changes and current limitations.
LAN quest/reward/save validation, internet/cross-emulator play, broad hardware
coverage and a complete campaign playthrough remain unverified. Experimental
interpolation can distort the background inside the hunter's house.
