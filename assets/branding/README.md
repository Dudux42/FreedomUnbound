# Freedom Unbound logo

## Windows executable icon

`freedom-unbound-icon.png` is a transparent square emblem derived from the V2
logo with the built-in imagegen tool on 11 October 2026. It retains the silver
mountain, forest green and emerald gem, omitting lettering for small-size use.
`freedom-unbound-icon.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel frames,
encoded from the PNG using Pillow's ICO writer. Both `FreedomUnbound.exe` and
`FreedomUniteNative.exe` embed the same icon through `host/app_icon.rc.in`.
The original full logos are retained.

Generation prompt: derive a compact square Windows application icon from the
V2 logo; preserve its angular silver snow-capped mountain, forest-green interior,
emerald diamond and silver ornamental frame; remove lettering; simplify into a
bold cohesive mountain-and-gem crest readable at small sizes; transparent alpha,
no background haze, dragon, wings or text. The PNG is the retained raster master.

`freedom-unbound-logo-v2.png` is the revised logo with the dragon and both wings removed. It retains the mountains, trees, green-and-silver lettering and decorative frame. Generated by editing v1 with the built-in image generation tool, preserving PNG alpha. The original v1 is retained for reference. V2 is embedded into the launcher executable and displayed at the top of the repository README.

## V2 edit prompt

Edit this Freedom Unbound logo. Remove the entire dragon/wyvern, including its head, neck, body, tail, and both large wings and their silver wing bones. Keep the exact FREEDOM UNBOUND lettering, its layout, green-and-silver palette, mountain-and-pine-tree crest, central green gem, and decorative frame around and beneath the lettering unchanged. The mountains should now be the topmost emblem, with a clean compact balanced silhouette and transparent space above and to the sides. Do not replace the dragon with any other creature or object. Preserve the original lettering and mountain artwork closely. Output the standalone logo on a genuinely transparent background, preserving alpha; remove any background haze outside the logo. No new text.

`freedom-unbound-logo-v1.png` is the first original logo concept for Freedom Unbound, generated with the built-in image generation tool. It uses green and silver lettering with a wyvern and mountain crest, matching the launcher's green accent direction. The PNG is 1536 by 1024 pixels with an alpha channel; the outer corner is transparent. This is a raster master, not a vector file or a small application icon. V1 is retained as a concept only.

## Final generation prompt

Use case: logo-brand. Create one polished original logo for a native PC hunting-game project named FREEDOM UNBOUND. Asset: a standalone transparent PNG logo for a dark modern desktop launcher. Exact text: "FREEDOM" on the first line and "UNBOUND" on the second, no other words. Bold carefully crafted uppercase lettering, excellent legibility, pale silver/off-white letter faces with restrained dark edging; UNBOUND slightly larger. Above and integrated with the lettering, a strong original symmetrical crest: an angular winged wyvern silhouette framing a sharp mountain peak, conveying adventure and freedom. The emblem must be simple enough to recognize at small sizes, with clean deliberate contours, not a busy illustration. Forest green and fresh leaf green accents matching a modern green launcher, restrained silver detail. Premium fantasy game identity with subtle engraved character, graphic and vector-friendly shapes, balanced compact stacked composition, generous transparent padding around the complete logo. No scenic background, no surrounding rectangle, no mockup, no watermark, no excessive glow, no tiny text, no copied Monster Hunter or other existing game logo. Real transparent background, retain alpha.
