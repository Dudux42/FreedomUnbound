# Launcher artwork

`modern-landscape.png` is original artwork generated with the built-in image generation tool for the Modern Minimal launcher. It is scenery only, with no game textures or third-party mod assets. The build embeds the image into the executable; portable packages do not need an external image file.

## Generation prompt

Create an original background-only illustration for a Modern Minimal desktop game launcher, widescreen 16:9. A clearly visible blue-hour mountain lake landscape, layered rocky peaks, pine forests framing the edges, a few warm lights in a tiny distant alpine village, soft moonlit clouds and mist. Elegant realistic painted concept art, slate blue and muted teal palette. Bright readable scenery and lifted shadows, moderate contrast, no crushed blacks; the mountains, trees and lake should be clearly visible at normal monitor brightness. Open spacious lake and sky in the center/right for a launcher title. Slightly darker left edge will sit behind a separate sidebar. No text, no UI, no borders, no logos, no people. This is scenery artwork only.

## Interface

Near-black navigation surfaces, green actions and off-white text. The scenery stays at its original brightness outside a small translucent title panel. One primary Play action; Settings, Mods, Saves, Game data and Quit remain available using mouse, keyboard or gamepad. Navigation scrolls in short windows. Mod development remains paused; this redesign preserves the existing Mods page without adding mod features.
